# UI/UX Principles - ITI 9-Month Journey

## Lesson 2: Design Systems and Efficient Design Workflow in Figma

As part of my learning journey at the Information Technology Institute (ITI), this lecture focused on the foundations of design systems and how to use Figma efficiently to create scalable, maintainable, and consistent designs.

Understanding these concepts is essential for designers working on large products, within design teams, or on complex interfaces.

---

## What Is a Design System?

A design system is a structured collection of reusable components, visual standards, and design guidelines that ensure consistency across digital products.

Instead of designing every UI element from scratch, teams rely on predefined components and clear rules.

A typical design system includes:

- Color palettes
- Typography system
- Spacing and layout rules
- Reusable UI components
- Interaction and behavior guidelines

Real-world examples:

- Google's Material Design
- IBM's Carbon Design System
- Microsoft's Fluent Design

These systems help teams build products faster while maintaining a consistent user experience.

## Figma Plugins and Widgets

Figma becomes significantly more powerful with plugins and widgets.

### Plugins

Plugins extend Figma's capabilities and help automate repetitive tasks.

Examples include:

- Generating avatars or placeholder content
- Accessibility checkers
- Icon libraries
- Data population tools
- Color palette generators

Plugins help designers save time and improve productivity.

### Widgets

Widgets are interactive tools used mainly for collaboration and teamwork inside Figma files.

Examples include:

- Voting widgets for design decisions
- Sticky notes for brainstorming
- Task or flow mapping tools

Widgets make it easier for teams to collaborate during the design process.

---

## Variables vs. Styles

Understanding the difference between styles and variables is essential for scalable design systems.

### Styles

Styles store reusable visual properties, such as:

- Color styles
- Text styles
- Effect styles (shadows, blurs)
- Grid styles

They help maintain visual consistency across screens.

Example:

A "Primary Button Text Style" ensures the same typography is applied everywhere.

### Variables

Variables allow designers to define dynamic values used across a design.

They can control properties such as:

- Colors
- Spacing
- Border radius
- Typography values

Variables also support modes, such as:

- Light mode
- Dark mode

Example:

Instead of manually updating colors for dark mode, you switch the variable mode and the entire interface updates automatically.

---

## Export Settings

Export settings help designers prepare assets for developers and production use.

Common export formats include:

- SVG for icons and scalable graphics
- PNG for UI images and assets
- JPG for compressed images
- PDF for documentation or sharing designs

Proper export preparation improves the design-to-development handoff process.

---

## Key Takeaways

- Design systems ensure consistency and scalability in products.
- Plugins and widgets significantly improve productivity and collaboration.
- Styles maintain visual consistency across designs.
- Variables allow dynamic design updates such as dark/light themes.
- Proper export settings streamline developer handoff.
