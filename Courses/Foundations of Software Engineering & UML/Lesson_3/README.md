# Lesson_3: Software Process Models

If the **SDLC** defines *what* must happen in a software project, the **Software Process Model** defines *how* to structure, organize, and execute those phases.

In this lesson, we explored the major process models used in the software industry — their strengths, limitations, and where each model fits best.

---

## 🔹 1. Waterfall Model

A **linear, sequential, and rigid** model where each phase must be completed before moving to the next.

### ✔ Advantages
- Clear documentation  
- Simple and easy to manage

### ❌ Limitations
- Difficult to accommodate changes  
- Late discovery of issues

**Best for:** Government systems, banking, healthcare, and projects with very stable requirements.

---

## 🔹 2. V-Model (Verification & Validation Model)

An extension of Waterfall that places **equal emphasis on development and testing**.

Each development phase has a corresponding testing phase.

### ✔ Advantages
- Strong focus on testing from day one  
- Clear mapping between build and test activities

**Best for:** Safety-critical systems (aerospace, automotive, medical devices).

---

## 🔹 3. Iterative Model

Build the system through **repeated cycles** (versions), improving it with each iteration.

### ✔ Advantages
- Continuous refinement  
- Reduces risk early  
- Early partial working software

**Best for:** Medium-sized projects with evolving requirements.

---

## 🔹 4. Incremental Model

Deliver the system in **small, functional increments** (v1, v2, v3...).

### ✔ Advantages
- Early delivery of usable features  
- Frequent customer feedback  
- Easier to test and manage

**Best for:** Web apps, mobile apps, SaaS platforms.

---

## 🔹 5. Agile Model

Focused on **short sprints**, constant user involvement, and rapid delivery.

### ✔ Advantages
- Highly flexible  
- Adapts quickly to changing requirements  
- Delivers value early and continuously  

**Best for:** Startups, SaaS products, most modern applications.

---

## 🔹 6. DevOps Model

A modern model focusing on **collaboration between development and operations**.

### ✔ Advantages
- CI/CD pipelines  
- Automation and continuous delivery  
- Real-time monitoring and reliability improvements  

**Best for:** Cloud systems, scalable distributed applications, enterprise solutions.

---

## ⭐ Key Takeaways

- No single model fits all projects — choose based on requirements, risk, and scope.  
- **Waterfall:** structured but rigid.  
- **Agile & DevOps:** fast, adaptive, customer-centric.  
- **Iterative & Incremental:** combine structure with continuous improvement.
