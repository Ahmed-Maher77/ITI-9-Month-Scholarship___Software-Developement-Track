# 🎓 Cyber Security Essentials — ITI 9-Month Journey  
## Lesson 15: Wireless Security & Best Security Practices

In this lesson, we explored how to secure wireless networks and apply essential security practices to protect systems, users, and data.

---

## 🔍 What We Covered

### **1️⃣ Wireless Security Standards**
Different wireless encryption protocols provide varying levels of protection:

- **WEP:** Weak, outdated, easily cracked  
- **WPA:** More secure but still outdated  
- **WPA2 / WPA3:** Modern, strong encryption standards  
- **Open Access:** No encryption — extremely risky  

**Real Example:** Public Wi-Fi in cafés typically uses **Open Access**, making users vulnerable to sniffing and man-in-the-middle attacks.

---

### **2️⃣ Wireless Access Controls**
Key access control measures to secure wireless environments:

- Disable **SSID broadcast** to reduce visibility  
- Enable **MAC address filtering**  
- Use strong **WPA2/WPA3** authentication methods  

---

### **3️⃣ Network Security Best Practices**
Essential real-world practices to protect networks and systems:

- ✔️ Secure physical access to routers, switches, and servers  
- ✔️ Change **default usernames/passwords**  
- ✔️ Keep operating systems **updated**  
- ✔️ Enable **antivirus and anti-malware** protections  
- ✔️ Configure **firewalls** correctly  
- ✔️ Implement **access control & permissions**  
- ✔️ Perform **regular backups**  
- ✔️ Use **anti-phishing tools** and browser protections  

---

## 🧠 Key Takeaways

- **WPA3** is currently the most secure wireless standard  
- Public networks require **high caution**  
- Security is a **continuous, proactive process**, not a one-time setup
