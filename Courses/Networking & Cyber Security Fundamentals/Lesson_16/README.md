# 🎓 Distributed Systems & Cloud — ITI 9-Month Journey  
## Lesson 16: Distributed Systems — Architecture, Use Cases & Real-World Examples

In this lesson, we explored how modern applications scale to millions of users by leveraging distributed system architectures.

---

## 🔍 Topics Covered

### 1️⃣ What Is a Distributed System?
A **distributed system** is a collection of independent computers that work together as a single system.  

**Example:** Google Search, Facebook, Uber live tracking.

---

### 2️⃣ Centralized vs Distributed Systems

| Aspect | Centralized | Distributed |
|--------|------------|------------|
| **Storage** | Data resides on a single machine. Easy to manage but risky. | Data is spread across multiple machines. |
| **Robustness** | Low. A single server failure can bring down the system. | High. Failure of one node does not affect overall operation. |
| **Scalability** | Limited. Hardware upgrades only scale vertically. | Horizontal scaling. Add more nodes to grow indefinitely. |

---

### 3️⃣ Distributed Architectures
- **Client-Server**  
- **Three-Tier**  
- **Multi-Tier (N-Tier)**  
- **Peer-to-Peer (P2P)**  

**Example:** Blockchain networks are built on P2P architectures.

---

### 4️⃣ Benefits
- ✔️ Fault tolerance  
- ✔️ Global low latency  
- ✔️ High availability  
- ✔️ Unlimited horizontal scalability  

---

### 5️⃣ Challenges
- ❗ Complex coordination between nodes  
- ❗ Data consistency and synchronization issues  
- ❗ Network failures  
- ❗ Overhead in maintaining state across nodes  

---

## 🧠 Key Takeaways

- Distributed systems power **modern large-scale applications**  
- **P2P** is the foundation of Blockchain technology  
- **Scalability** is achieved by adding more machines horizontally
