# 🎓 Cloud Computing & Virtualization — ITI 9-Month Journey  
## Lesson 17: Virtualization & Cloud Models (IaaS, PaaS, SaaS)

In this lesson, we explored the backbone of modern IT infrastructure — **virtualization** and **cloud computing**, and how they enable scalable, flexible, and cost-efficient solutions.

---

## 🔍 Topics Covered

### 1️⃣ Virtualization
Virtualization allows running **multiple operating systems** on a single physical machine.

**Benefits:**
- ✔️ Cost reduction  
- ✔️ Redundancy  
- ✔️ Isolation of environments  
- ✔️ Easy migration  

**Example:** Running **Windows and Linux simultaneously** on VirtualBox.

---

### 2️⃣ Cloud Computing — On-Demand Resources
Cloud computing delivers a **pool of shared computing resources** (compute, storage, networking) over the internet on-demand.

---

### 3️⃣ Cloud Service Models

| Model | Description | Example |
|-------|-------------|--------|
| **IaaS** | You manage OS and applications; provider manages hardware | AWS EC2 |
| **PaaS** | Deploy applications without managing servers | Heroku |
| **SaaS** | Ready-to-use applications | Gmail, Zoom |

---

### 4️⃣ Cloud Deployment Models
- **Public Cloud:** Shared resources, managed by providers  
- **Private Cloud:** Dedicated resources for a single organization  
- **Hybrid Cloud:** Combination of public & private clouds  
- **Community Cloud:** Shared among organizations with similar needs  

---

## 🧠 Key Takeaways

- Virtualization provides **efficiency and flexibility**  
- Cloud computing enables **scalable, cost-effective, global resources**  
- IaaS, PaaS, SaaS define **shared responsibilities** between provider and user
