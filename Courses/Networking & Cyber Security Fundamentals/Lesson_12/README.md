# 🎓 Cyber Security Essentials — ITI 9-Month Journey  
## Lesson 12: Information Security Basics — CIA, Risks & Threat Landscape

Understanding the fundamentals of **Information Security** is the starting point of every cybersecurity path.  
In this lesson, we explored the core security goals, key risk concepts, and attacker methodologies that shape today’s threat landscape.

---

## 🔍 Topics Covered

### 1️⃣ CIA Triad — The Core Security Goals
The **CIA Triad** guides all cybersecurity strategies:

#### 🔹 Confidentiality  
Protecting data from unauthorized access.  
**Example:** Encrypting sensitive files.

#### 🔹 Integrity  
Ensuring data remains accurate and unaltered.  
**Example:** Using hashing to detect tampering.

#### 🔹 Availability  
Ensuring systems and data are accessible when needed.  
**Example:** Implementing backups and redundant systems.

---

### 2️⃣ Risks, Threats & Vulnerabilities

- **Threat:** Anything that can cause harm  
  *Examples: malware, attackers, hardware failures*

- **Vulnerability:** A flaw or weakness that can be exploited  
  *Examples: outdated software, weak passwords*

- **Risk:** The likelihood of a threat exploiting a vulnerability  
  **Formula:**  
  **Risk = Threat × Vulnerability**

**Example Scenario:**  
An outdated server (vulnerability) + ransomware (threat) → data loss (risk)

---

### 3️⃣ Attacker Methodology & Common Attack Types

Attackers often follow a structured workflow:

1. **Reconnaissance**  
2. **Scanning**  
3. **Gaining Access**  
4. **Maintaining Access**  
5. **Covering Tracks**

**Common Attack Types:**
- Phishing  
- Brute Force  
- Malware  
- Denial of Service (DoS)  
- Social Engineering  

Understanding these patterns helps anticipate and defend against real threats.

---

## 🧠 Key Takeaways

- ✔️ The CIA Triad is the foundation of cybersecurity  
- ✔️ Risk happens when a threat exploits a vulnerability  
- ✔️ Studying attacker behavior leads to better defenses
