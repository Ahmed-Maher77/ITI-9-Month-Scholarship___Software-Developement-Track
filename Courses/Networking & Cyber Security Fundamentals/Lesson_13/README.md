# 🎓 Cyber Security Essentials — ITI 9-Month Journey  
## Lesson 13: Security Defenses — Firewalls, DMZ, IDS & IPS

In this lesson, we explored the essential security technologies organizations use to protect their networks from internal and external threats.

---

## 🔍 Topics Covered

### 1️⃣ Firewalls — The First Line of Defense
Firewalls control and filter traffic between networks.

#### 🔹 Types of Firewalls:
- **Stateless (Packet Filtering):**  
  Filters based on IP, port, and MAC addresses.
- **Stateful:**  
  Tracks active connections and session state.
- **NGFW (Next-Generation Firewall):**  
  Offers deep packet inspection, application control, IPS, VPN, and web filtering.

**Real Example:**  
An NGFW can block social media sites for employees while allowing business applications.

---

### 2️⃣ DMZ — Demilitarized Zone
A protected buffer zone used to host **public-facing services**, such as:
- Web servers  
- FTP servers  
- Mail servers  

The DMZ prevents direct exposure of the internal network to the internet.

---

### 3️⃣ IDS & IPS — Detecting and Preventing Attacks
- **IDS (Intrusion Detection System):**  
  Detects malicious activity and generates alerts.
- **IPS (Intrusion Prevention System):**  
  Detects and blocks threats automatically, in real-time.

#### Detection Methods:
✔️ Signature-based  
✔️ Anomaly-based  
✔️ Behavior-based  

**Example:**  
An IPS can instantly detect and block a SQL injection attack targeting a company website.

---

### 4️⃣ Proxy Servers
A proxy acts as an intermediary between users and the internet, providing:
- IP masking  
- URL filtering  
- Access control  

**Example:**  
Schools use proxy rules to restrict student access to specific websites.

---

### 5️⃣ VPN — Secure Tunneling
VPNs create encrypted tunnels to secure communication across untrusted networks.

#### Types:
- **Remote Access VPN**  
- **Site-to-Site VPN**  

---

## 🧠 Key Takeaways

✔️ NGFW offers advanced, multi-layered security  
✔️ DMZ isolates public services from internal networks  
✔️ IDS detects threats — IPS actively blocks them  
✔️ VPN ensures secure, encrypted communication
