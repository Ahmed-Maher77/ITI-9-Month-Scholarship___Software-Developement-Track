## 📘 What I Learned Throughout the Course

### 🔵 Part 1 — Network Essentials
- Core networking concepts, terminologies, and communication models  
- Network categories: transmission modes, geographic scope, administration  
- Network topologies and data flow  
- OSI & TCP/IP layers and protocol mapping  
- Key protocols: HTTP/S, DNS, FTP, DHCP, ARP, RIP, OSPF, SMTP, POP3, IMAPv4  
- MAC addressing, frames, switching, collision/broadcast domains  
- IP addressing, routing basics, packet forwarding  
- TCP vs UDP, ports, segmentation, reliability  
- Network devices: routers, switches, hubs, cables, wireless media  

### 🔵 Part 2 — Cyber Security Essentials
- CIA Triad and core security principles  
- Threats, vulnerabilities, attacker motivations & attack lifecycle  
- Malware families and behavior  
- IDS vs IPS, firewalls (static/dynamic/NGFW), proxies, VPNs  
- Cryptography basics: symmetric/asymmetric keys, signatures, certificates  

### 🔵 Part 3 — Distributed Systems
- Design goals: scalability, transparency, fault tolerance, availability  
- Client-server, peer-to-peer, clustered & cloud-based models  
- The four architectures: Layered, Object-based, Data-centered, Event-based  
- Real-world systems: Google, Amazon, WhatsApp, CDNs  
- Cloud models (IaaS / PaaS / SaaS) & deployment types (public / private / hybrid)

### 🔵 Hands-On Labs
- Static & DHCP IP configuration  
- Using ipconfig, ping, arp, route  
- DNS checks (nslookup)  
- FTP server/client setup  
- Port monitoring (netstat)  
- Windows Firewall rules  
- Remote Desktop (RDP)  
- SMTP/POP3/IMAP operations  
- VM & network setup  
- Packet flow & routing analysis  
- Mitigating DoS attacks with firewall rules
