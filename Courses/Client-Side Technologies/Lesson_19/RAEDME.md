# 🎓 Client-Side Technologies — ITI 9-Month Journey

## Lesson_19: JavaScript Cookies & Error Handling

In this lesson, I focus on two important pillars of client-side programming: state management using cookies and robust error handling in JavaScript.

The attached slides explain why cookies exist, how they compensate for the stateless nature of HTTP, and how they are used in real-world scenarios such as authentication, personalization, and maintaining user state. The lesson also highlights cookie types, limitations, security considerations, and how cookies are created, read, and deleted using JavaScript, with a brief look at modern storage alternatives.

Additionally, this lesson covers JavaScript error handling mechanisms, introducing the Error object, common built-in error types, and practical techniques for detecting and managing runtime issues using try...catch, throw, finally, and the onerror event.

This lesson reinforces best practices for building reliable, fault-tolerant, and user-friendly web applications.
