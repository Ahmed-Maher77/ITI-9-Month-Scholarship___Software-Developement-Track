# Client-Side Technologies - ITI 9-Month Journey

## Lesson 10: Introduction to CSS (Cascading Style Sheets)

In this lesson, I begin my journey with CSS, the technology that turns raw HTML into visually structured, user-friendly web interfaces.

The attached slides and the presentation I sent beside cover the core foundations of CSS, including why it exists, how it works, and how it is applied in real-world projects. You get a clear understanding of separation of concerns, CSS syntax and rules, different ways to apply styles, the cascading and priority logic, and the most commonly used selectors that form the base of modern web design.

This lesson sets the groundwork for everything that follows, from layout systems and responsive design to animations and advanced UI techniques.
