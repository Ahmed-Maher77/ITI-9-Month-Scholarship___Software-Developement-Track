# Client-Side Technologies - ITI 9-Month Journey

## JavaScript Functions, Scope, and Built-in Objects

### Overview

This lesson deepens core JavaScript fundamentals by focusing on how code is structured, executed, and managed at runtime.

### Key Topics

- Functions: execution flow, parameters, return behavior, and ES6 features
- Scope and lifetime: global, local, and block scope, plus hoisting and the Temporal Dead Zone
- Debugging: common error types and practical troubleshooting techniques
- Objects: custom and built-in objects, plus the BOM and DOM foundations
- Core built-ins: String, RegExp, Number, and Math in real-world usage

### Takeaway

These concepts strengthen the ability to write predictable, maintainable, and debuggable JavaScript code.
