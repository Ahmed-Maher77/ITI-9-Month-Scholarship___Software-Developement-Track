# 🎓 Client-Side Technologies — ITI 9-Month Journey

## Lesson 16: JavaScript Built-in Objects & Browser Object Model (BOM)

In this lesson, I explore some of the most practical and frequently used JavaScript built-in objects, along with an introduction to the Browser Object Model (BOM), which defines how JavaScript interacts with the browser environment itself.

### 📚 What This Lesson Covers

The attached slides cover core objects such as:

- **Array** - Collections and data manipulation
- **Object** - Object creation patterns and properties
- **Date** - Working with dates and times
- **Boolean** - Truthy and falsy values

This lesson focuses on their structure, properties, and commonly used methods in real-world scenarios. It also clarifies important concepts like truthy and falsy values, object creation patterns, and how JavaScript handles collections of data.

### 🌐 Browser Object Model (BOM)

Additionally, this lesson introduces the BOM hierarchy, explaining:

- The `window` object as the global context for client-side execution
- Essential browser-related objects and features:
    - Dialogs
    - Window control
    - Scrolling
    - Timers

### 🎯 Learning Outcomes

This lesson bridges the gap between JavaScript language fundamentals and browser-level interactions, laying the foundation for:

- Event handling
- DOM manipulation
- Building interactive web experiences
