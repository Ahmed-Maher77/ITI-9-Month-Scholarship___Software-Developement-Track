## 📚 Introduction

The World Wide Web (WWW) is a massive network that connects billions of users, systems, and applications worldwide. It works thanks to **three core pillars**:

1. **Uniform Resource Locators (URLs)** — Unique addresses for web resources
2. **Protocols (HTTP/HTTPS)** — Rules for secure communication
3. **Hypertext (HTML)** — Links that connect web pages together

These elements form the backbone of everything we do on the web — from browsing websites to using complex web applications.

---

## 🕸 What Is a Website?

A website is a collection of interlinked web pages stored on a server and displayed through a browser.

Each web page is built using **client-side technologies**:

| Layer               | Technology | Role                           |
| ------------------- | ---------- | ------------------------------ |
| Content & Structure | HTML       | Defines the page structure     |
| Presentation        | CSS        | Controls layout, colors, fonts |
| Behavior            | JavaScript | Adds interactivity and logic   |

Together, these technologies make up the **Front End** — what users see and interact with.

---

## 🧠 Key Takeaways

✅ The Web depends on URLs, HTTP, and HTML  
✅ Websites are built using HTML, CSS, and JavaScript  
✅ Client-side technologies define structure, style, and behavior
