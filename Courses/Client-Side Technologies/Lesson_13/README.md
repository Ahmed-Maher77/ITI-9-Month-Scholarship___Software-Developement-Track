# 🎓 Client-Side Technologies — ITI 9-Month Journey

## Lesson 13: CSS Cascade, Specificity & the Box Model

In this lesson, I dive deeper into CSS fundamentals and advanced concepts that directly impact how styles are applied, overridden, and rendered in real web applications.

The attached slides explore the CSS cascade and specificity system, explaining how conflicts between styles are resolved and why some rules take precedence over others. They also introduce the CSS Box Model, which is essential for understanding spacing, sizing, and layout behavior of HTML elements.

Additionally, this lesson covers advanced selectors and combinators, core styling properties for text, fonts, colors, and backgrounds, commonly used measurement units, and the concept of inheritance—all of which are critical for writing predictable, maintainable, and scalable CSS.

This lesson builds the mental model needed to debug styling issues and design layouts with confidence.
