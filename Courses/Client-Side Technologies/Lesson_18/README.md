# 🎓 Client-Side Technologies — ITI 9-Month Journey

## Lesson_18: JavaScript Forms & Event Model

In this lesson, I focus on form manipulation and the JavaScript event model, two essential areas for building interactive, user-driven web applications on the client side.

The attached slides explain how JavaScript works with HTML forms, including accessing form objects, handling form elements, validating user input, and controlling form submission and reset behavior. The lesson also explores different event types and event-binding techniques, showing how user interactions such as clicks, typing, and mouse movements are captured and handled.

Additionally, this lesson introduces the Event Object and the concept of event propagation (capturing, target, and bubbling phases), along with important methods like `preventDefault()` and `stopPropagation()`. Advanced topics such as custom (synthetic) events and practical use of the `this` keyword are also covered.

This lesson lays the groundwork for building robust forms, clean event handling logic, and responsive user interfaces.
