# 🎓 Client-Side Technologies — ITI 9-Month Journey

## Lesson_17: JavaScript Execution Model, BOM & DOM

In this lesson, I explore how JavaScript runs inside the browser, moving beyond syntax into understanding the execution model and how JavaScript interacts with both the browser and the document.

### 📚 Learning Materials

**📊 Slides:** [JavaScript_Runtime_BOM_DOM.pdf](JavaScript_Runtime_BOM_DOM.pdf)

The attached slides explain how JavaScript operates as a single-threaded language, how synchronous and asynchronous code are handled through the call stack, heap, Web APIs, callback queue, and event loop, and why this model is essential for building responsive web applications.

### 📖 Topics Covered

This lesson also dives deeper into the Browser Object Model (BOM), covering key browser-related objects such as:

- **navigator** - Information about the browser
- **location** - Current URL and navigation
- **history** - Browser navigation history
- **screen** - Display information

Followed by an introduction to the Document Object Model (DOM) as a standardized API for accessing and manipulating HTML content:

- Core element selection methods
- Document properties and collections
- Event handling concepts

This lesson forms a critical foundation for DOM manipulation, event-driven programming, and interactive UI development in the upcoming sessions.
