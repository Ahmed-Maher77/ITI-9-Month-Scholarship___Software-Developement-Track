## Lesson 11: CSS Cascade, Specificity & the Box Model

---

## 📘 Overview

In this lesson, I dive deeper into CSS fundamentals and advanced concepts that directly impact how styles are applied, overridden, and rendered in real web applications.

The attached slides explore:

- **CSS Cascade and Specificity System** — How conflicts between styles are resolved and why some rules take precedence over others
- **CSS Box Model** — Essential for understanding spacing, sizing, and layout behavior of HTML elements
- **Advanced Selectors and Combinators** — Targeting elements with precision
- **Core Styling Properties** — Text, fonts, colors, and backgrounds
- **Measurement Units** — Understanding px, em, rem, %, vh, vw, and more
- **Inheritance** — How properties are passed down from parent to child elements

This lesson builds the mental model needed to debug styling issues and design layouts with confidence.
