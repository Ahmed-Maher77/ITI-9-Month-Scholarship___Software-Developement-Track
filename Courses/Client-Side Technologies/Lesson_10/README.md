# 🎓 Client-Side Technologies — ITI 9-Month Journey

## Lesson 10: Introduction to CSS (Cascading Style Sheets)

---

## 📘 Overview

In this lesson, I start my journey with CSS, the technology responsible for transforming raw HTML into visually structured, user-friendly web interfaces.

The attached slides cover the core foundations of CSS, including:

- Why CSS exists and how it works
- How it's applied in real-world projects
- Understanding separation of concerns
- CSS syntax and rules
- Different ways to apply styles
- The cascading and priority logic
- The most commonly used selectors that form the base of modern web design

This lesson sets the groundwork for everything that follows — from layout systems and responsive design to animations and advanced UI techniques.
