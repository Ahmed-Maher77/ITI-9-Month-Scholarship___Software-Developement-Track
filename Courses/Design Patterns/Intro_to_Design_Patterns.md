# Introduction to Design Patterns

Design patterns are proven, reusable solutions to common software design problems. They capture best practices and architectural approaches that improve clarity, maintainability, and communication across teams.

Why patterns matter
- Provide a shared vocabulary for design decisions.
- Reduce duplicated design effort by reusing established solutions.
- Improve code flexibility and testability when applied appropriately.

Classification
- Creational: patterns that simplify object creation (e.g., Singleton, Factory, Builder).
- Structural: patterns that compose classes or objects to form larger structures (e.g., Adapter, Facade, Decorator).
- Behavioral: patterns that manage algorithms, responsibilities, and object interactions (e.g., Observer, Strategy, Command).
