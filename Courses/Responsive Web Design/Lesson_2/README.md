# Responsive Web Design (RWD) — ITI 9-Month Professional Training Program

Lesson 2: Flexbox Layout Model

## Introduction

In the second part of the lecture, we explored Flexbox, a powerful one-dimensional CSS layout model designed to align elements efficiently and distribute space dynamically.

---

## Flexbox Structure and Axes

- **Flex container:** The parent element
- **Flex items:** The children inside the container
- **Main axis and cross axis:** Define layout direction and alignment behavior

---

## Flex Container Properties

- `display: flex | inline-flex`
- `flex-direction`
- `flex-wrap`
- `flex-flow`
- `justify-content` (main axis alignment)
- `align-items` (cross axis alignment)
- `align-content` (multi-line alignment)
- `gap` (spacing between items)

**Example:**
Perfectly centering a card horizontally and vertically using Flexbox with minimal CSS.

---

## Flex Item Properties

- `order`
- `flex-grow`
- `flex-shrink`
- `flex-basis`
- `flex` (shorthand)
- `align-self` (override container alignment)

**Example:**
Creating a layout where the main content grows dynamically while the sidebar maintains a fixed width.

---

## Practical Application

We applied these concepts through hands-on tasks, progressing from simple alignment challenges to building full layouts with header, sidebar, main content, and footer.

---

## Key Takeaways

- Flexbox simplifies layout logic
- Alignment becomes predictable and scalable
- Ideal for navigation bars, cards, and page sections
