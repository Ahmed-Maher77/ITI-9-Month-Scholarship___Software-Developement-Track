# 🎓 Relational Databases (PostgreSQL) — ITI 9-Month Journey

## Lesson_1 — Part 1: Database Fundamentals

Databases are the backbone of modern software systems.

From banking platforms and e-commerce websites to social media apps and enterprise SaaS solutions — structured data management is essential.

In this lesson, I started my journey with PostgreSQL by understanding the core database fundamentals 👇

---

### 🔹 What is a Database?

A database is an organized collection of related data that can be stored, accessed, and managed efficiently.

**Example:**

A university system stores:

- Students
- Courses
- Instructors
- Departments
- Grades

Instead of spreadsheets or text files, databases provide structured storage with high reliability and performance.

---

### 🔹 What is DBMS?

A DBMS (Database Management System) is software used to:

- Store data
- Retrieve data
- Update data
- Secure data
- Maintain consistency between related data

**Examples:**

PostgreSQL, MySQL, Oracle, SQL Server

---

### 🔹 What is RDBMS?

An RDBMS (Relational Database Management System) stores data in structured tables connected using relationships.

Each table contains:

- Rows → records
- Columns → attributes

Relationships between tables are created using Primary Keys and Foreign Keys.

**Example:**

**Students Table**

StudentID | Name | Email

**Courses Table**

CourseID | CourseName

**Enrollments Table**

StudentID | CourseID

---

## 🔑 Key Takeaways

- ✔️ A database organizes structured data efficiently
- ✔️ DBMS manages storage, retrieval, and security
- ✔️ RDBMS connects tables using relationships
