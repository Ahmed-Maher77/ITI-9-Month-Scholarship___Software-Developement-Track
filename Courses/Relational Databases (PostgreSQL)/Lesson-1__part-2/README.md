## Lesson_1 — Part 2: Why PostgreSQL?

After understanding database fundamentals, we explored why PostgreSQL is one of the most powerful database systems used in real-world applications today 👇

---

### 🔹 What is ORDBMS?

PostgreSQL is not just an RDBMS — it is an ORDBMS (Object-Relational DBMS).

This means it combines:

Relational structure (tables + relationships)

-

Object-oriented capabilities (custom types, arrays, JSON, composite types)

This makes PostgreSQL flexible enough for modern application architectures.

---

### 🔹 Why PostgreSQL?

PostgreSQL is widely used in production environments because it is:

- ✅ Open-source and free
- ✅ Cross-platform (Windows, Linux, macOS)
- ✅ Highly stable and reliable
- ✅ Designed for high-volume applications
- ✅ Extensible and standards-compliant

It supports advanced modern features such as:

- JSON / JSONB storage
- Arrays
- Stored Procedures & Functions
- Triggers
- Transactions (ACID compliance)
- Indexing for performance optimization
- Custom data types

These capabilities make PostgreSQL suitable for both startups and enterprise-level systems.

---

### 🔹 PostgreSQL History (Quick Insight)

PostgreSQL originated from the POSTGRES research project at the University of California, Berkeley, led by Prof. Michael Stonebraker.

Later evolution:

POSTGRES → Postgres95 → PostgreSQL

Today, PostgreSQL is considered one of the most advanced open-source relational database systems available.

---

## 🔑 Key Takeaways

- ✔️ PostgreSQL is an Object-Relational DBMS (ORDBMS)
- ✔️ It supports modern enterprise-grade features
- ✔️ It is widely used in scalable real-world systems
