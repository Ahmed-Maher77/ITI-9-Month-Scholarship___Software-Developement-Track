## ⚙️ How does Generative AI actually work?

At a high level, Generative AI works in three main stages:

1. **Training:**  
   Models learn patterns, language structure, and relationships from massive datasets.

2. **Inference:**  
   When you enter a prompt, the model predicts the most likely next tokens based on context.

3. **Generation:**  
   The model produces a coherent response — which can sometimes include errors if context or data is missing.

📌 This explains why AI can be powerful yet still hallucinate and require human review.

## 🧰 Models & Tools You should know

Modern AI tools are built on advanced models and are already used in daily workflows:

- ChatGPT — reasoning, coding, analysis, content, and multimodal tasks
- Gemini — strong multimodal and Google ecosystem integration
- Claude — long-context understanding and safety-focused responses
- Microsoft Copilot — AI embedded in productivity tools
- Poe — access to multiple AI models in one place

Advanced models include:

- GPT-4o — fast, multimodal, general-purpose
- GPT-o1 — optimized for deep reasoning
- Sora — text-to-video generation
