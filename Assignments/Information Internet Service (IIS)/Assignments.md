# IIS Server Configuration Assignment

## Goal

Convert your local machine into a web server using Internet Information Services (IIS), then configure network identity and secure access.

## Assignment Requirements

1. Install and enable IIS on your local machine.
2. Create and host a website in IIS.
3. Define and document a static IP address for the server.
4. Configure and document a custom domain name mapped to your local server.
5. Configure HTTPS by creating or installing an SSL certificate and binding it to your website.

## What You Must Submit

- Screenshots showing each completed step.
- A short report that includes:
    - Server IP address
    - Domain name used
    - SSL certificate details (issuer, validity period, and binding)
- Final test results showing the site is accessible with both domain name and HTTPS.

## Validation Checklist

- IIS is running.
- Website loads successfully.
- Domain name resolves to your server IP.
- HTTPS works without connection errors.
