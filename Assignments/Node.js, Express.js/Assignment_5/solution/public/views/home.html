Lab 3 • Products & Categories API
Node.js + Express + MongoDB

Welcome. Your API Is Ready for CRUD Operations.

This project exposes category and product endpoints with Mongoose models. Use the routes below to create, read, update, and delete records.

Open Categories Open Products
POST/api/categories
GET/api/categories
GET/api/categories/:categoryId/products
POST/api/products
GET/api/products
GET/api/products/:id
PUT/api/products/:id
DELETE/api/products/:id
If an endpoint path is wrong, the custom 404 page will be shown.
