- Write a script to create different shapes (rectangle, square, circle, triangle) that all inherit from polygon.

## 2) Proxy

Create a dynamic object using Proxy such that it has only the following properties:

- `name` property that accepts only a string of 7 characters.
- `address` property that accepts only string values.
- `age` property that accepts numerical values between 25 and 60.

## 3) Promise
