## Assignment 1: Dynamic Array

**Description**: Implement a dynamic array with basic operations: insert, remove, find, resize, copy constructor, and print.

**Objectives**:
- Understand dynamic memory allocation in C++.
- Implement constructors and destructors.
- Implement array resizing and element management.

## Assignment 2: Binary Heap (Priority Queue)

**Description**: Implement a min-heap with operations: insert, removeMin, removeFrom, heapifyUp, and heapifyDown.

**Objectives**:
- Understand heap data structure and its properties.
- Implement insertion and deletion while maintaining heap property.
- Practice using C++ vectors and recursive algorithms.
