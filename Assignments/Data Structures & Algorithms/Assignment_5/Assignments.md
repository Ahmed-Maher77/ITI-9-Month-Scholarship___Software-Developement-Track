# Data Structures & Algorithms Assignments

This repository contains my **Data Structures and Algorithms assignments**, implemented in **C++** as part of my academic practice.

Each assignment focuses on implementing core data structures from scratch and applying fundamental algorithms.

---

## 📌 Assignment 1: Hash Table (Separate Chaining)

### 📄 Description
Implementation of a **generic hash table** using:
- Templates (`KeyType`, `ValueType`)
- Separate chaining with `std::list`
- Custom hash function using `std::hash`

### ✨ Features
- Insert key-value pairs
- Remove elements
- Search (`Contains`)
- Lookup values by key
- Clear the table (`MakeEmpty`)

### 📂 Solution

`Solutions/HashTable/HashTable.cpp`

## 📌 Assignment 2: Graph (Adjacency Matrix)

### 📄 Description
