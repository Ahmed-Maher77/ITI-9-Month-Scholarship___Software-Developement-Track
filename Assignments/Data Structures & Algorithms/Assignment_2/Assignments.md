# Data Structures Assignments (C++)

This repository includes a set of assignments implemented in **C++** using
object-oriented programming and core data-structure fundamentals.

Each assignment focuses on building and implementing custom data structures
without relying on STL containers, to strengthen understanding of:

- Dynamic memory management  
- Double Linked Lists  
- Inheritance  
- Sorting and searching  
- Stack and Queue operations  
- Copy constructor & assignment operator  
- Operator overloading  

---

## 📌 Assignments Overview

### **Task 1 — Sorted Double Linked List**
Implement a **Sorted Doubly Linked List** supporting:
- Insert sorted by ID  
- Search  
- Delete  
- Display  
- Destructor  
- Copy constructor  

👉 **Solution:** `Solutions/task1_sorted_dll.cpp`

---

### **Task 2 — Stack using DLL Inheritance**
- Implement a `StackDLL` class that inherits from `DLL`
- Uses `insertAtFront()` and `deleteFromFront()`
- Supports:
  - `push()`
  - `pop()`
  - `peek()`

👉 **Solution:** `Solutions/task2_stack_dll.cpp`

---

### **Task 3 — Queue using DLL Inheritance**
- Implement a `Queue` class extending `DLL`
- Supports:
  - `enqueue()`
  - `dequeue()`
  - `peek()`
  - Display all  
  - Menu-based program

👉 **Solution:** `Solutions/task3_queue_dll.cpp`

---

### **Task 4 — Full Double Linked List**
Implement a complete **Double Linked List** with:

- Constructor  
- Destructor  
- Copy Constructor  
- Copy Assignment Operator  
- `operator[]`
- `AddNode`
- `DeleteNode`
- `SearchList`
- `DisplayNode`
- `NodeNumber`

👉 **Solution:** `Solutions/task4_full_dll.cpp`
