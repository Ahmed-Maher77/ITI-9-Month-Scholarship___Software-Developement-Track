# Client-side Technologies Assignments

## JavaScript Fundamentals

### A. Event Object

1. **Prevent context menu**
    - Prevent the default action when the user right-clicks on the page.
2. **Form submission confirmation**
    - Display a confirmation message when the form is submitted.
    - Stop submission if user chooses "Cancel"; proceed if "OK".
3. **Custom Event (`custEvent`)**
    - Fire a custom event after 30 seconds if no data has been entered by the user.
4. **Key events difference**
    - Compare the behavior of `keydown` and `keypress` for Ctrl, Alt, and Shift keys.
5. **Detect key pressed**
    - Use the event object to detect both the physical key pressed and the character produced.
    - Bonus: prevent default browser behavior for specific key combinations.
