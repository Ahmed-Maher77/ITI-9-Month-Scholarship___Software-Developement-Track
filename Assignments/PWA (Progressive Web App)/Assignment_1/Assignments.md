# Assignment 1 - PWA Tasks


## Overview

Complete the following tasks to finalize the PWA features and testing.

## Tasks

1. Implement all topics covered in the sessions.
2. Add a custom install button that triggers the PWA install prompt.
3. Handle offline state with a custom page that says: "You are working offline" and includes an anchor tag back to the home page.
4. Handle invalid URL requests with a custom page that says: "Wrong URL" and includes an anchor tag back to the home page.
5. Cache any new network requests.
6. Run and test the website on your mobile device.
