# HTML5 & CSS3 - Assignment 1: Lab Tasks

## Overview

This assignment consists of five HTML5 and CSS3 lab tasks designed to practice and reinforce fundamental web development skills including form validation, responsive design, CSS animations, and advanced CSS techniques.

---

## Task 1: Form Validation with Email

### Objective

Create a form with input validation using HTML5 patterns and CSS styling to provide visual feedback.

### Requirements

- Build a "Change Email Address" form with username and email fields
- Implement HTML5 pattern validation:
    - **Username**: 8+ alphabetic characters only
    - **Email**: Valid email format with alphanumeric characters and '@' symbol
- Add CSS styling to show:
    - **Green border** for valid inputs
    - **Red border** for invalid inputs
    - **Error messages** displayed only when input is invalid
- Style the submit button with appropriate hover effects
- Responsive design with centered form layout

### Files

- `task-1/index.html` - Form structure
- `task-1/style.css` - Form styling and validation feedback

### Key Concepts

- HTML5 form validation patterns
- CSS pseudo-classes (`:valid`, `:invalid`)
- Form styling and user experience

## Task 2: Responsive Image Display

### Objective

Implement an image display that adapts responsively to different screen sizes.

### Requirements

- Display an image with proper HTML5 semantic markup
- Implement responsive image sizing using CSS
- Ensure the image scales appropriately on different devices
- Maintain aspect ratio and prevent distortion
- Use appropriate alt text for accessibility

### Files

- `task-2/index.html` - Image markup
- `task-2/style.css` - Responsive styling
- `task-2/images/` - Image assets

### Key Concepts

- Responsive image implementation
- CSS viewport units
- Image optimization for web

## Task 3: Button Hover Animation

### Objective

Create an interactive button with a blinking animation effect triggered on hover.

### Requirements

- Create a button element with text "Hover to Blink"
- Implement CSS animations for hover effects
- Add a blinking animation that triggers on hover
- Smooth transitions and polished user interaction
- Cross-browser compatible animation

### Files

- `task-3/index.html` - Button structure
- `task-3/style.css` - Animation and hover effects

### Key Concepts

- CSS animations and transitions
- Pseudo-class selectors (`:hover`)

## Task 4: Playing Card Design

### Objective

Create a playing card design using pure CSS shapes and positioning techniques.

### Requirements

- Build an A of Hearts playing card using HTML and CSS
- Create card structure with:
    - Top-left character indicator
    - Center design with heart symbol
    - Triangle shape for decoration
    - Bottom-right character indicator (rotated)
- Use CSS for all shapes (no images except SVG if needed)
- Proper positioning and layout
- Visually accurate playing card appearance

### Files

- `task-4/index.html` - Card markup
- `task-4/style.css` - Card styling and CSS shapes

### Key Concepts

- CSS shapes and positioning
- Transform and rotation properties
- Flexbox/Grid layouts
- Advanced CSS techniques

## Task 5: Pokemon Character Design

### Objective

Create a stylized Pokemon character design entirely with HTML and CSS.

### Requirements

- Implement proper proportions and details
- Add colors and effects to match Pokemon aesthetic

### Files

- `task-5/index.html` - Pokemon markup
