# Assignment 1

## Overview

This assignment focuses on applying creational design patterns and core object-oriented design concepts covered in Session 1.

## Tasks

1. Implement a counter that tracks the number of active instances.
2. Implement the creation of a new document from an existing document. Each document should include a header, footer, pages, and text.
3. Implement a PizzaBuilder in which the pizza definition remains hidden from the customer.
