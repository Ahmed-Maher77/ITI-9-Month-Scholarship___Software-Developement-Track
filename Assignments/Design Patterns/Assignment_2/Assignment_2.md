# Assignment 2

## Overview

This assignment focuses on structural design patterns covered in Session 2 and their practical use in TypeScript.

## Tasks

1. Implement the Decorator design pattern so a teacher object can be extended with dynamic properties such as salary, nationality, and street.
2. Implement the Proxy design pattern for retrieving countries, with support for cached and non-cached data.
3. Implement the Bridge design pattern so TV and speaker share the same interface of increase_volume, decrease_volume, and mute. Two bridge implementations should support increase and decrease, while one should also support mute.
4. Implement the Composite design pattern for a box of books with page counts that displays the hierarchy.
