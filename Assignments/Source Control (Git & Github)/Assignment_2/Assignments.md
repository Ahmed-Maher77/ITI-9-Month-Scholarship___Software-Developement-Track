# Assignment: Git Workflow Task

## Task Description

This assignment requires you to demonstrate your ability to work with Git and GitHub following professional software development practices. You will create a new project locally, manage branches, merge updates, create tags, and collaborate by inviting a contributor. Follow the steps below:

### 1. Create and Push a New Project

* Initialize a new project on your local machine.
* Initialize Git and make the first commit.
* Add a remote repository on GitHub.
* Push the initial project to the remote repository.

### 2. Create and Manage Branches

* Create two new branches: **dev** and **test**.
* On each branch, create a new file (one file per branch).
* Commit the changes and push both branches to the remote repository.

### 3. Merge Changes Into Main

* Switch back to the **main** branch locally.
* Merge both **dev** and **test** branches into **main**.
* Resolve any merge conflicts if they appear.
* Push the updated **main** branch to the remote repository.

### 4. Create an Annotated Tag

* Create an **annotated tag** with the name: `v1.7`.
* Push the tag to the remote repository.

### 5. Add a Contributor

* Send an invitation to your instructor by adding them as a collaborator/contributor in the GitHub repository settings.
